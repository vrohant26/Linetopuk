Reliable Visitor
Counters Built to Last

Collaborative approach

Linetop visitor counters deliver accurate, long-term people and traffic monitoring for any environment. Durable sensors record visitors, vehicles, or cyclists, with options from basic totals to precise time logs.

Wireless indoor sensors and outdoor units connect easily to PC software for instant data, charts, and reports. Low-cost batteries last up to a year, ensuring 5–10 years of reliable, low-maintenance performance.

With secure enclosures, free software updates, and no ongoing fees, Linetop counters offer a smart, cost-effective visitor tracking solution.

Our Products

1

Visitor Data Loggers – Plug-and-Play Counters

Linetop data loggers offer simple, plug-and-play operation with any visitor sensor in any location. They automatically adjust to different movement speeds so each person is counted once. Data collection is easy—just replace the coloured memory cube and read it later at a PC, avoiding the need for laptops or handheld devices. This reliable system keeps visitor monitoring consistent and effortless.

2

Control Box for Visitor Counters – Simple Setup Anywhere

Each logger is configured with our plug-in Control Box, as easy to use as setting a digital watch. With simple buttons, you can set the date, time, and sensor options in seconds. One Control Box works with all loggers, making it a cost-effective, field-ready tool. Powered by the logger’s own batteries, it needs no extras and doesn’t store data—just swap the flash memory cubes for that. Compact and durable, it’s a reliable essential for managing visitor counters anywhere.

3

Wireless Visitor Data Links – Real-Time Footfall Monitoring

In staffed sites like visitor centres, live visitor data can transmit instantly via radio to a local PC, removing the need for data loggers. Visitor traffic is stored directly to a networked drive, ready for local or remote access. Linetop’s EcoPC software processes this live data into clear tables and charts, revealing footfall trends in real time. Easy to use yet powerful, it helps manage facilities and report visitor activity efficiently.

4

Windows PC Apps for Visitor Counters – Numero & EcoPC

Linetop offers two Windows apps for simple visitor data management. Numero reads memory cubes, links data to sites, adjusts counts, and exports results to EcoPC. EcoPC compiles all counter data over any period to create clear charts and tables for reports. Together, they deliver fast, reliable analysis of visitor flow and trends—without ongoing licence fees.
